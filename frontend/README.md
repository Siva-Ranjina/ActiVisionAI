# Human Activity Recognition Using Deep Learning

A deep learning project that recognizes human activities from video sequences using Convolutional Neural Networks (CNNs).

## Activities Detected
- Biking
- Jumping Jack
- Playing Guitar
- Push-ups
- Walking with Dog

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib

## Dataset
UCF101 Human Action Recognition Dataset.

## Project Workflow
1. Video preprocessing and frame extraction
2. Model training
3. Model evaluation
4. Activity prediction from video sequences

## Project Structure
```text
Human-Activity-Recognition-DL/
```

## Objective
To explore deep learning techniques for automatic human activity recognition from video data.
